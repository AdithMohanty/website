# Personal Website

Adith Mohanty's personal site — built with [Next.js](https://nextjs.org).

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Edit content

All page content lives in the `experience` and `projects` arrays in
[`app/page.tsx`](app/page.tsx). Logos and images are in `public/media/`.

## Deploy

Hosted on Vercel — pushing to `main` triggers an automatic deploy.
